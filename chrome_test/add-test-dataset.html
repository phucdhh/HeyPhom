🧪 Add Test Dataset to HeyPhom

This tool adds the chrome_test dataset to your HeyPhom localStorage for testing

📋 Instructions:

  • 1. Click "Select Images" and choose the chrome_test/test-images/ folder
  • 2. Click "Add Dataset to HeyPhom" to save it to localStorage
  • 3. Open HeyPhom → Settings → Saved Datasets
  • 4. Select "chrome_test" and click "🚀 Build"
  • 5. Watch it upload and build the 3D model!
